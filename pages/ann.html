ANN Visualizer: Konsep Artificial Neural Network

Artificial Neural Network (ANN) adalah model komputasi yang terinspirasi oleh jaringan neuron biologis manusia. Pelajari bagaimana sinyal input diproses melalui lapisan tersembunyi (Hidden Layers), dipengaruhi oleh bobot (Weights) dan bias, serta diaktifkan menuju output prediksi.

⚡

Tujuan Pembelajaran Modul Ini:

  • Membedakan fungsi Input Layer, Hidden Layer, dan Output Layer.
  • Memahami peran matematis Bobot (Weights / w) dan Bias (b) pada setiap koneksi sinapsis.
  • Menjelaskan peran fungsi aktivasi (ReLU dan Sigmoid) dalam menangkap pola non-linear data bisnis.
  • Melihat simulasi animasi Forward Propagation (aliran data dari input ke output).

Bagaimana Artificial Neural Network 'Belajar'?

1. Forward Pass (Perhitungan Maju)

Data fitur pelanggan (input) dikalikan dengan bobot koneksi sinapsis, dijumlahkan dengan bias, lalu dilewatkan ke fungsi aktivasi di setiap lapisan hingga menghasilkan prediksi akhir.

2. Loss Calculation (Hitung Selisih Error)

Membandingkan tebakan output model dengan label aktual (misal: tebakan peluang 0.85 vs aktual membeli 1.0). Menghasilkan nilai rugi (Loss).

3. Backpropagation & Gradient Descent

Error dialirkan mundur ke belakang untuk menyesuaikan dan memperbaiki seluruh nilai bobot koneksi. Proses diulang ribuan kali (epoch) hingga error seminimal mungkin.

ℹ️
Transparansi Pembelajaran: Visualisasi Animasi Bukan Pelatihan Model Nyata
Animasi denyut sinyal di atas adalah simulasi grafis konseptual untuk membantu mahasiswa memahami alur data matematika di dalam jaringan saraf. Pelatihan model Deep Learning nyata memerlukan ribuan iterasi tensor matrix dan hardware komputasi yang intensif.

📌 Ringkasan Penting Materi Ini

  • Neuron menghitung kombinasi linier: $\sum w_i x_i + b$ lalu diubah oleh fungsi aktivasi.
  • Fungsi aktivasi memberi fleksibilitas: Memungkinkan model memetakan batas keputusan non-linear yang sangat rumit.
  • ANN adalah model black-box: Sulit menjelaskan secara intuitif kepada direksi cafe alasan di balik setiap angka bobot, berbeda dengan Decision Tree yang transparan.
