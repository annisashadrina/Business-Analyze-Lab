Classification Lab: Prediksi Customer Churn

Berbeda dengan regresi yang menebak angka, klasifikasi memprediksi kategori kelas (misal: "Berhenti Berlangganan" vs "Tetap Langganan"). Pelajari pohon keputusan, cara membaca Confusion Matrix, dan konsekuensi bisnis False Positive vs False Negative.

🎯

Tujuan Pembelajaran Modul Ini:

  • Membedakan klasifikasi kategori (diskrit) dari regresi prediksi angka (kontinu).
  • Memahami alur pemikiran pohon keputusan (Decision Tree) dan prinsip peluang Naive Bayes.
  • Membaca Confusion Matrix 2x2: True Positive (TP), False Positive (FP), False Negative (FN), dan True Negative (TN).
  • Menghitung dan menginterpretasikan metrik: Akurasi, Presisi, Recall, dan F1-Score.

Pendeteksian Missing Values & Imputasi Median

Menemukan kolom yang memiliki nilai kosong dan mengisinya dengan nilai median agar ukuran sampel tidak berkurang akibat penghapusan baris (*drop*).

Python (Google Colab Cell 3 - 4) 
# 1. Periksa jumlah missing values di setiap kolom
print("Jumlah Missing Values Sebelum Imputasi:")
print(df_churn.isnull().sum())

# 2. Hitung nilai Median untuk kolom numerik (pengeluaran_ribu)
# Alasan: Median tahan terhadap outlier dibandingkan mean
median_spending = df_churn['pengeluaran_ribu'].median()
print(f"\nNilai Median Pengeluaran: Rp {median_spending * 1000:,.0f}")

# 3. Terapkan imputasi fillna dengan median
df_churn['pengeluaran_ribu'].fillna(median_spending, inplace=True)

# 4. Verifikasi kembali bahwa missing values telah tuntas diatasi
print("\nJumlah Missing Values Setelah Imputasi Median:")
print(df_churn.isnull().sum())
Output Terminal / Notebook:

💡 Prinsip Analisis Bisnis:
Menghapus baris pelanggan yang memiliki nilai kosong (*drop row*) berisiko menimbulkan *selection bias*. Mengisi dengan nilai tengah (median) mempertahankan volume observasi tanpa merusak distribusi statistik secara ekstrem.

One-Hot Encoding untuk Variabel Kategorikal

Mengonversi kolom teks seperti komplain_terakhir menjadi representasi numerik biner (0 / 1) menggunakan OneHotEncoder dari Scikit-Learn.

Python (Google Colab Cell 5) 
from sklearn.preprocessing import OneHotEncoder

# 1. Inisialisasi OneHotEncoder (sparse_output=False agar menghasilkan array 2D standar)
encoder = OneHotEncoder(sparse_output=False)

# 2. Tentukan fitur teks/kategorikal yang perlu di-encode
categorical_cols = ['komplain_terakhir']

# 3. Transformasi fitur kategorikal ke dalam DataFrame angka biner
df_encoded_cats = pd.DataFrame(
    encoder.fit_transform(df_churn[categorical_cols]),
    columns=encoder.get_feature_names_out(categorical_cols)
)

# 4. Hapus kolom string asli dan gabungkan fitur biner hasil encoding
df_churn_clean = df_churn.drop(categorical_cols, axis=1)
df_final = pd.concat([df_churn_clean, df_encoded_cats], axis=1)

print("Tampilan DataFrame setelah One-Hot Encoding:")
print(df_final.head(3))
Output Kolom Baru Hasil Encoding:
['customer_id', 'lama_langganan_bulan', 'frekuensi_pesan_per_bulan', 'pengeluaran_ribu', 'churn', 'komplain_terakhir_Tidak', 'komplain_terakhir_Ya']
💡 Mengapa Harus One-Hot Encoding?
Algoritma matematika dan pohon keputusan tidak bisa menghitung string teks "Ya" dan "Tidak". Melalui One-Hot Encoding, "Ya" diubah menjadi kolom komplain_terakhir_Ya = 1, memungkinkan kalkulasi matematis tanpa mengasumsikan urutan nilai (*ordinal bias*).

Seleksi Fitur ($X$), Variabel Target ($Y$), & Train-Test Split (70:30)

Memisahkan variabel input dari target churn, lalu membagi data 70% untuk melatih model dan 30% untuk pengujian independen.

Python (Google Colab Cell 6 - 9) 
from sklearn.model_selection import train_test_split

# 1. Pilih Fitur (X): Buang ID Pelanggan dan label Churn
X = df_final.drop(['customer_id', 'churn'], axis=1)

# 2. Tentukan Sasaran Prediksi / Target (y)
y = df_final['churn']

# 3. Bagi data menjadi Training Data (70%) dan Testing Data (30%)
# Menggunakan random_state=42 agar pembagian acak selalu konsisten/reproducible
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, shuffle=True, random_state=42
)

# 4. Tampilkan proporsi pembagian data
print(f"Bentuk X_train (Data Latih) : {X_train.shape}")
print(f"Bentuk X_test  (Data Uji)   : {X_test.shape}")
print(f"Bentuk y_train (Label Latih): {y_train.shape}")
print(f"Bentuk y_test  (Label Uji)  : {y_test.shape}")
Output Terminal / Notebook:
Bentuk X_train (Data Latih) : (11, 5)
Bentuk X_test  (Data Uji)   : (5, 5)
Bentuk y_train (Label Latih): (11,)
Bentuk y_test  (Label Uji)  : (5,)
💡 Kaidah Anti-Overfitting:
Jangan pernah menguji performa model menggunakan data yang sama dengan data latihnya! Itu ibarat membocorkan kunci jawaban ujian sebelum tes dimulai. Train-Test Split 70:30 memastikan evaluasi model mencerminkan kemampuannya dalam memprediksi pelanggan baru di dunia nyata.

Pemodelan & Visualisasi Decision Tree (Pohon Keputusan)

Melatih model pohon keputusan Scikit-Learn dengan parameter min_impurity_decrease=0.01 dan memvisualisasikan diagram percabangannya.

Python (Google Colab Cell 10 - 11) 
import matplotlib.pyplot as plt
from sklearn import tree

# 1. Inisialisasi model Decision Tree
# min_impurity_decrease=0.01 memangkas cabang jika penurunan impurity tidak signifikan (pruning)
dtc = tree.DecisionTreeClassifier(min_impurity_decrease=0.01, random_state=42)

# 2. Latih model dengan data training
dtc.fit(X_train, y_train)

# 3. Visualisasikan diagram pohon keputusan menggunakan Matplotlib
plt.figure(figsize=(14, 7))
tree.plot_tree(
    dtc,
    max_depth=3,           # Membatasi kedalaman agar mudah dibaca & tidak lag
    filled=True,           # Warna kotak menandai dominasi kelas
    rounded=True,
    class_names=['Tetap', 'Churn'],
    feature_names=X_train.columns
)
plt.title("Arsitektur Pohon Keputusan: Prediksi Churn Pelanggan", fontsize=14, fontweight='bold')
plt.tight_layout()
plt.show()

# 4. Lakukan prediksi pada data uji (X_test)
y_pred_dtc = dtc.predict(X_test)
print("Hasil Prediksi Decision Tree pada Data Uji:")
print(y_pred_dtc)
Output Terminal / Notebook:
Visualisasi pohon berhasil di-render.
Hasil Prediksi Decision Tree pada Data Uji: ['Ya' 'Tidak' 'Ya' 'Tidak' 'Tidak']
💡 Keunggulan Decision Tree untuk Stakeholder Bisnis:
Decision Tree adalah algoritma yang paling mudah dijelaskan kepada manajemen non-teknis (*white-box model*). Anda dapat menunjukkan dengan jelas: "Jika frekuensi belanja ≤ 2x dan ada komplain, pelanggan 85% berisiko kabur."

Evaluasi Confusion Matrix & Metrik Bisnis Lengkap

Menghitung matriks kesalahan 2x2, Akurasi, Presisi, Recall, F1-Score, dan Cohen's Kappa Score dari kedua model.

Python (Google Colab Cell 12, 13, 15, 16) 
from sklearn import metrics

# 1. Confusion Matrix untuk Decision Tree
cm_dtc = metrics.confusion_matrix(y_test, y_pred_dtc)
print("=== Confusion Matrix (Decision Tree) ===")
print(cm_dtc)

# 2. Perhitungan Metrik Evaluasi Komprehensif (Decision Tree)
acc_dtc = metrics.accuracy_score(y_test, y_pred_dtc)
prec_dtc = metrics.precision_score(y_test, y_pred_dtc, pos_label='Ya')
rec_dtc = metrics.recall_score(y_test, y_pred_dtc, pos_label='Ya')
f1_dtc = metrics.f1_score(y_test, y_pred_dtc, pos_label='Ya')
kappa_dtc = metrics.cohen_kappa_score(y_test, y_pred_dtc)

print(f"\nAkurasi (Accuracy)  : {acc_dtc:.4f}")
print(f"Presisi (Precision) : {prec_dtc:.4f}")
print(f"Recall (Sensitivitas): {rec_dtc:.4f}  <-- Krusial untuk mendeteksi pelanggan churn!")
print(f"F1-Score            : {f1_dtc:.4f}")
print(f"Cohen's Kappa Score : {kappa_dtc:.4f}")

# 3. Hitung juga metrik untuk Naive Bayes

Komparasi Kurva ROC-AUC & Pembuatan Tabel Prediksi Akhir (df_compare)

Membandingkan trade-off sensitivitas vs false alarm menggunakan Kurva ROC, menghitung skor AUC, dan mengekspor tabel hasil komparasi prediksi.

Python (Google Colab Cell 17 - 21) 
import matplotlib.pyplot as plt

# 1. Ambil probabilitas kelas positif ('Ya') untuk membuat kurva ROC
y_pred_dtc_proba = dtc.predict_proba(X_test)[:, 1]
y_pred_gnb_proba = gnb.predict_proba(X_test)[:, 1]

# 2. Hitung False Positive Rate (FPR), True Positive Rate (TPR), dan AUC
fpr_dtc, tpr_dtc, _ = metrics.roc_curve(y_test, y_pred_dtc_proba, pos_label='Ya')
auc_dtc = metrics.roc_auc_score(y_test, y_pred_dtc_proba)

fpr_gnb, tpr_gnb, _ = metrics.roc_curve(y_test, y_pred_gnb_proba, pos_label='Ya')
auc_gnb = metrics.roc_auc_score(y_test, y_pred_gnb_proba)

# 3. Visualisasikan Komparasi Kurva ROC
plt.figure(figsize=(8, 6))
plt.plot(fpr_dtc, tpr_dtc, label=f"Decision Tree (AUC = {auc_dtc:.3f})", color="#6366f1", lw=2)
plt.plot(fpr_gnb, tpr_gnb, label=f"Naive Bayes (AUC = {auc_gnb:.3f})", color="#06b6d4", lw=2)
plt.plot([0, 1], [0, 1], 'k--', lw=1.5, label="Random Guess (AUC = 0.500)")
plt.title("Perbandingan Kurva ROC: Decision Tree vs Naive Bayes", fontweight='bold')
plt.xlabel("False Positive Rate (1 - Specificity)")
plt.ylabel("True Positive Rate (Recall)")
plt.legend(loc="lower right")
plt.grid(True, alpha=0.3)
plt.show()

# 4. Buat DataFrame Hasil Komparasi Prediksi Aktual vs Model
df_compare = X_test.copy()
df_compare['Kelas_Aktual'] = y_test
df_compare['Prediksi_DecisionTree'] = y_pred_dtc
df_compare['Prediksi_NaiveBayes'] = y_pred_gnb

print("\n=== Tabel Perbandingan Hasil Prediksi Akhir ===")
print(df_compare.head())

Pertimbangan Finansial & Risiko

🎯 Analisis Trade-off: False Positive vs False Negative

Dalam kasus pencegahan pelanggan berhenti langganan (churn) di Kedai Kopi Senja, kesalahan manakah yang jauh lebih merugikan bagi profit jangka panjang bisnis?

📌 Ringkasan Penting Materi Ini

  • Klasifikasi memprediksi kelas: Output berupa Ya/Tidak, Churn/Tetap, atau kategori diskrit.
  • Confusion matrix membedakan jenis error: Akurasi tinggi bisa menipu jika dataset tidak seimbang (imbalance class).
  • Pilih metrik sesuai biaya bisnis: Jika False Negative fatal, utamakan Recall daripada Presisi murni.
