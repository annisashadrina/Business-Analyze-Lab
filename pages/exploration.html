Data Exploration & Ringkasan Statistik

Exploratory Data Analysis (EDA) adalah proses memahami sifat alami data sebelum melakukan pemodelan: melihat pola sebaran, menghitung nilai pusat, mendeteksi korelasi awal, dan memverifikasi kesehatan dataset.

🔍

Tujuan Pembelajaran Modul Ini:

  • Membaca metrik ringkasan statistik: total baris, jumlah kolom, nilai kosong, rata-rata, min, dan max.
  • Memvisualisasikan tren dan korelasi menggunakan Bar Chart, Line Chart, dan Scatter Plot.
  • Menghubungkan visualisasi data dengan padanan perintah praktikum Python pandas (head, info, describe).
  • Menjawab pertanyaan eksplorasi bisnis berdasarkan grafik observasi.

Data dihitung langsung dari data/coffee_sales.csv menggunakan Chart.js lokal tanpa internet.
🐍

Jembatan Konsep: Padanan Kode Python Pandas

Saat Anda melakukan praktikum di Jupyter Notebook atau Google Colab, tampilan visual di atas dihasilkan melalui perintah-perintah Python berikut:

1. Membaca Ukuran Data
import pandas as pd
df = pd.read_csv("coffee_sales.csv")
print(df.shape) # Output: (14, 6)
Menampilkan jumlah baris (14) dan kolom (6).
2. Mengintip Baris Teratas
print(df.head(5))
Menampilkan 5 baris pertama untuk memverifikasi isi data.
3. Ringkasan Statistik Deskriptif
print(df.describe())
Menghitung rata-rata (mean), min, max, dan persentil kolom angka.
Pertanyaan Eksplorasi

🎯 Analisis Pola Grafik Observasi

Amati grafik batang atau scatter plot di atas, lalu jawab pertanyaan bisnis berikut:

Berdasarkan data observasi 14 hari, pada hari apakah produk terjual mencapai kuantitas tertinggi, dan pola apa yang terlihat?

📌 Ringkasan Penting Materi Ini

  • Grafik membantu mendeteksi tren tersembunyi: Pola lonjakan akhir pekan terlihat jauh lebih jelas pada grafik daripada membaca tabel mentah.
  • Scatter plot mengungkap korelasi: Hubungan searah antara biaya promosi dan produk terjual mengindikasikan kelayakan analisis regresi.
  • EDA menjawab apa yang terjadi: Namun untuk memprediksi masa depan, kita membutuhkan model statistik atau machine learning.
