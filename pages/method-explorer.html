Modul 05 • Navigasi Metodologi

Method Explorer: Memilih Metode Sesuai Pertanyaan Bisnis

Kesalahan paling sering terjadi pada mahasiswa adalah memilih algoritma karena terlihat canggih, bukan karena cocok dengan pertanyaan bisnis dan struktur datanya. Gunakan wizard interaktif ini untuk menemukan metode yang tepat.

🧭

Tujuan Pembelajaran Modul Ini:

  • Mampu memetakan pertanyaan bisnis ke dalam rumpun analitik: Supervised vs Unsupervised.
  • Membedakan kebutuhan data antara Regresi (angka kontinu), Klasifikasi (kategori), Clustering (jarak), dan Association Rules (transaksi).
  • Menggunakan wizard pohon keputusan bercabang untuk merekomendasikan metode analisis.
  • Menyadari jebakan umum (pitfall) pada setiap metode agar tidak salah interpretasi hasil.
Pohon Keputusan Interaktif

Katalog Lengkap Metode Analisis

Pelajari rangkuman karakteristik, tujuan, dan batasan tiap metode:

📈
Supervised

Linear Regression

Memprediksi angka kontinu (rupiah, penjualan, durasi) berdasarkan relasi matematis variabel input.

Target: Angka Kontinu Buka Lab →
🎯
Supervised

Classification (Decision Tree / Naive Bayes)

Memetakan data pelanggan ke dalam label kelas diskrit (misal: Churn vs Tetap, Bayar vs Gagal).

Target: Kategori Kelas Buka Lab →
👥
Unsupervised

Clustering (K-Means)

Mengelompokkan baris data berdasarkan kedekatan jarak fitur belanja tanpa butuh label target awal.

Target: Unlabeled Data Buka Lab →
🛒
Pattern Mining

Association Rules (Apriori)

Menemukan kombinasi item produk kasir yang sering dibeli bersamaan untuk bundling dan tata letak toko.

Target: Struk Transaksi Buka Lab →
⚡
Deep Learning

ANN (Artificial Neural Network)

Jaringan berlapis neuron untuk memodelkan interaksi fitur kompleks non-linear multi-dimensi.

Target: Kompleks Non-Linear Buka Lab →
💬
NLP / Sentimen

Text Mining & Sentimen

Ekstraksi opini dan sentimen dari ulasan teks pelanggan Google Maps melalui pipeline pemrosesan kata.

Target: Teks Bebas Buka Lab →

📌 Ringkasan Penting Materi Ini

  • Mulai dari target: Apakah target Anda angka (Regresi) atau kategori (Klasifikasi)?
  • Tidak ada target? Gunakan Unsupervised: Kelompokkan pelanggan dengan Clustering atau cari kombinasi menu kasir dengan Association Rules.
  • Pahami keterbatasan: Setiap model memiliki asumsi data yang harus divalidasi sebelum disajikan ke manajemen.
